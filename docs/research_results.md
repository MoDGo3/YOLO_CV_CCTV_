## 1.1 การจำแนกเพศ (Gender Classification)

### ตารางที่ 1.1: ผลการทดสอบการจำแนกเพศ (Gender Classification)

| ค่าวัดผล | ความหมายและคุณภาพเพื่อวัด | การคำนวณ | ผลลัพธ์ |
|----------|---------------------------|----------|---------|
| **ความเที่ยงตรงรวม** | วัดส่วนทางการทำนายที่ถูกต้อง จากการทำนายทั้งหมด<br>สูตร: $\frac{TP+TN}{Total}$ | $\frac{3476}{5000}$ | **69.5%** |
| **ความละเอียด** | วัดความสามารถในการทำนายว่าตามที่ระบบบอก อย่าง 'ชาย' นั้นจริงๆ<br>สูตร: $\frac{TP}{TP+FP}$ | เฉลี่ย Man + Woman | **75.7%** |
| **ความครอบคลุม** | วัดระบบนันส่วนที่ระบุได้แล้วของทุกผล<br>สูตร: $\frac{TP}{TP+FN}$ | เฉลี่ย Man + Woman | **68.4%** |
| **คะแนน F1** | ค่าเฉลี่ยสอดแบบ Harmony (เฉลี่ย) ระหว่างความละเอียดและความครอบคลุม ความสมดุล<br>สูตร: $2 \times \frac{Precision \times Recall}{Precision + Recall}$ | เฉลี่ย Man + Woman | **66.8%** |

### รายละเอียดแต่ละ Class (Gender):

| Class | Precision | Recall | F1-Score | Support |
|-------|-----------|--------|----------|---------|
| **Man (ชาย)** | 0.642 | 0.942 | 0.764 | 2,611 |
| **Woman (หญิง)** | 0.871 | 0.425 | 0.571 | 2,389 |
| **เฉลี่ย** | **0.757** | **0.684** | **0.668** | **5,000** |

### สูตรการคำนวณ (Gender Classification):

```
Accuracy = (TP + TN) / (TP + TN + FP + FN) = 3,476 / 5,000 = 69.5%

Precision (Man) = TP / (TP + FP) = 2,460 / (2,460 + 1,373) = 0.642
Precision (Woman) = TP / (TP + FP) = 1,016 / (1,016 + 151) = 0.871

Recall (Man) = TP / (TP + FN) = 2,460 / (2,460 + 151) = 0.942
Recall (Woman) = TP / (TP + FN) = 1,016 / (1,016 + 1,373) = 0.425

F1 Score (Man) = 2 × (0.642 × 0.942) / (0.642 + 0.942) = 0.764
F1 Score (Woman) = 2 × (0.871 × 0.425) / (0.871 + 0.425) = 0.571
```

## สูตรคำนวณทั่วไป

### Accuracy (ความแม่นยำ)
```
Accuracy = (TP + TN) / (TP + TN + FP + FN)
```
**ความหมาย**: สัดส่วนการทำนายที่ถูกต้องทั้งหมด

### Precision (ความละเอียด)
```
Precision = TP / (TP + FP)
```
**ความหมาย**: จากที่ระบบทำนายเป็น Positive มีกี่ส่วนที่ถูกต้องจริง

### Recall (ความครอบคลุม / Sensitivity)
```
Recall = TP / (TP + FN)
```
**ความหมาย**: จากที่เป็น Positive จริง ระบบจับได้กี่ส่วน

### F1 Score (คะแนน F1)
```
F1 Score = 2 × (Precision × Recall) / (Precision + Recall)
```
**ความหมาย**: ค่าเฉลี่ยฮาร์โมนิกของ Precision และ Recall เพื่อความสมดุล

## อธิบายข้อมูลเพิ่มเติม

### ข้อมูลทดสอบ:
- **Dataset**: FairFace Dataset (Balanced Demographic Dataset)
- **จำนวนรูปทดสอบ (Gender)**: 5,000 รูป
- **จำนวนรูปทดสอบ (Ethnicity)**: 3,256 รูป
- **โมเดล**: DeepFace (backend: ssd)
- **ที่มา**: Karkkainen & Joo, 2021

### คำอธิบายสัญลักษณ์:
- **TP (True Positive)**: ทำนายถูก เป็น Positive
- **TN (True Negative)**: ทำนายถูก เป็น Negative
- **FP (False Positive)**: ทำนายผิด เป็น Positive (แต่จริงๆ เป็น Negative)
- **FN (False Negative)**: ทำนายผิด เป็น Negative (แต่จริงๆ เป็น Positive)

## วิเคราะห์ผล

### Gender Classification (69.5% Accuracy):
- ✅ **จุดแข็ง**: Recall สำหรับ Man สูงมาก (94.2%) - จับได้เกือบทุกคน
- ⚠️ **จุดอ่อน**: Recall สำหรับ Woman ต่ำ (42.5%) - พลาดเยอะ
- 📊 **สาเหตุ**: โมเดลมีแนวโน้มทำนายเป็น Man มากเกินไป

### Ethnicity Classification (50.8% Accuracy):
- ✅ **จุดแข็ง**: Indian มี Precision สูงสุด (78.5%)
- ⚠️ **จุดอ่อน**: Latino Hispanic แม่นยำต่ำที่สุด (F1: 44.2%)
- 📊 **Fairness Gap**: 28% (ระหว่าง Black 69.0% และ Latino 44.2%)

### สรุปภาพรวม:
- Gender Classification ดีกว่า Ethnicity (69.5% vs 50.8%)
- ต้องปรับปรุง recall สำหรับ Woman และ accuracy สำหรับ Latino
